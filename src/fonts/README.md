`NotoSerifTibetan-Tibetan.woff2` is the Tibetan-script subset (U+0F00–0FFF) of
the variable [Noto Serif Tibetan](https://fonts.google.com/noto/specimen/Noto+Serif+Tibetan)
font, as served by Google Fonts. It is licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org).

Only the Tibetan subset is bundled so Latin text keeps the system font.

# Tibetan audio recordings

Drop one MP3 per item in this folder, named exactly as below. Lessons, the
Characters tab and the guidebook play `/audio/tibetan/<id>.mp3`. A missing file
is skipped silently and the phonetic text is still shown.

Record Lhasa/Central Tibetan, one clear take per file, trimmed to the sound itself.

Some words share an id with a letter (`nga`, `ja`) because they sound the
same; one file covers both.
